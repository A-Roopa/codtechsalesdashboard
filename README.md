Objective of the Dataset:

The main objective is to analyze sales data from various retail outlets and product categories using Power BI. The dataset helps understand sales trends, item performance, and outlet-wise contributions. It supports informed business decision-making through interactive dashboards and visualizations.

Key Activities:
1)Data Loading and Exploration:
Imported the sales dataset using Power BI's “Get Data” feature.
Explored column names, data types, and structure using Power Query Editor.

2)Display Dataset Overview:
Reviewed 1,559 data rows including sample values and metadata.
Identified the structure and scope for further analysis.

3)Summary Statistics:
Calculated key metrics (min, max, average) for numerical fields like Item_MRP, Item_Weight, Item_Outlet_Sales.
Analyzed category distributions in columns such as Item_Type, Outlet_Type.

4)Graphical Visualizations:
Bar Charts to compare total sales across item types or outlet types.
Pie Charts to visualize percentage share of product lines or outlets.
Line Graphs to depict sales trends over time.
Clustered Column Charts for comparing sales across multiple product and outlet categories.
Interactive features such as slicers and filters added for deep data exploration.

Outcomes:
Successfully built an insightful sales dashboard highlighting key sales metrics.
Gained a comprehensive understanding of product-wise and outlet-wise sales performance.
Enabled dynamic decision-making using filters and interactive visuals.
Identified trends, outliers, and top/bottom performing categories.
Laid the groundwork for further predictive analysis and business intelligence reporting.
